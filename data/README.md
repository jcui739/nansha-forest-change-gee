# Data Sources

No raw raster data is committed to this repository. All data is accessed via Google Earth Engine at runtime.

| Dataset | License / Terms |
|---|---|
| ESA WorldCover v200 | ESA WorldCover Terms of Use (free for research) |
| Landsat C2 L2 | USGS Landsat Public Domain |
| Dynamic World V1 | Google Earth Engine Terms (free for research) |

To reproduce: open GEE Code Editor, run the scripts in `gee/`, then export GeoTIFFs to Drive and run `analyze.py` locally.
